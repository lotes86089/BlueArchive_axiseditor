# 保守程式碼縮減設計

## 目標

縮減 `app.py` 中確認為重複或未使用的程式碼，同時維持既有功能、畫面、元件位置、資料格式與操作流程完全不變。

## 修改範圍

- 移除從未被讀取的拖曳狀態指派。
- 移除永遠為空的 `back_entries` 執行期狀態；儲存資料仍固定輸出 `back=[]`，並保留 `Axis.back` 以讀取舊資料。
- 簡化轉場刪除按鈕的 callback 建立方式，避免建立後再遍歷元件覆寫。
- 以單一小型 helper 正規化 `exam_phases` 與 `normal_phases`，保留 list 淺拷貝、字串轉換及 P1 舊備註 fallback。
- 以單一 helper 執行備註更新後的「載入、依 ID 替換、儲存」，保留找不到 ID 時不新增資料的既有行為。

## 明確不修改

- 不變更任何 Tkinter 元件、尺寸、顏色、間距、文字、排列或事件綁定。
- 不合併兩套拖曳或捲動實作。
- 不移除 `c_vars`、`time_vars` 或其他涉及橫排刪除互動的平行狀態。
- 不移除舊版 `front`、`back`、`c_text`、`time_text`、`c_items`、`time_items` 相容欄位。
- 不更改 JSON 結構、儲存順序或錯誤傳遞方式。
- 不新增套件。

## 驗證

- 執行 Python 語法編譯檢查。
- 以臨時資料檔驗證舊版與目前格式的載入、子軸正規化及備註儲存。
- 啟動 GUI 並建立／切換主要頁面，確認沒有 Tkinter 例外。
- 比對修改前後既有 `axes.json`，不改動使用者資料。
- 確認 Git diff 只包含本規格列出的程式縮減。

## 完成條件

所有驗證通過、使用者資料未被修改、介面與流程沒有可觀察差異，且程式碼總行數淨減少。
